สรุปข้อมูลที่มี
Drawdown ของพอร์ตรวม (%)
Drawdown = ระยะห่างจากจุดสูงสุดของมูลค่าพอร์ตที่เคยทำได้ ยิ่งติดลบมากยิ่งเสี่ยงสูง คำนวณจากหน่วยลงทุนสะสม ณ แต่ละวันคูณ NAV วันนั้น
XIRR / CAGR รายกองทุน (ผลตอบแทนทบต้นต่อปีที่แท้จริง)
กองทุนเงินลงทุนสุทธิมูลค่าปัจจุบันXIRR (ต่อปี)
XIRR คำนวณจากกระแสเงินสดจริง (วันที่ซื้อ/ขายแต่ละรายการ) จึงแม่นกว่า % ผลตอบแทนแบบง่ายเมื่อมีการเข้าซื้อหลายครั้งไม่สม่ำเสมอ
TWR — Time-Weighted Return (พอร์ตรวม)
TWR ตัดผลกระทบจากจังหวะเงินเข้า-ออกทิ้ง วัดเฉพาะฝีมือ/ผลการเติบโตของกองทุนเอง — ต่างจาก XIRR ที่รวมผลของจังหวะที่เราเติมเงินเข้าไปด้วย ใช้เทียบกับดัชนีตลาดหรือกองทุนอื่นที่ไม่มีเงินเข้าออกแบบเดียวกันได้แม่นกว่า
Contribution to Return — สัดส่วนกำไร/ขาดทุนที่แต่ละกองทุน "ดัน" พอร์ตรวม
กองทุนเงินลงทุนสุทธิกำไร/ขาดทุนReturn ของกองทุนเองContribution ต่อพอร์ตรวม
Contribution ต่อพอร์ตรวม = กำไร/ขาดทุนของกองทุนนั้น ÷ เงินลงทุนสุทธิของทั้งพอร์ต (ผลรวมของทุกกองทุนจะเท่ากับ Simple Return รวมพอร์ตพอดี) ต่างจาก "Return ของกองทุนเอง" ที่วัดผลตอบแทนเทียบกับเงินที่ลงในกองทุนนั้นเพียงกองเดียว — กองทุนที่ return % สูงแต่เงินลงทุนน้อย อาจ contribution ต่ำกว่ากองทุนที่ return % ต่ำกว่าแต่ถือเงินก้อนใหญ่ ตัวเลขนี้เป็น simple return สะสม (ไม่ทบต้นรายปีเหมือน XIRR)

Risk-free rate % ต่อปี
กองทุนผลตอบแทนต่อปี (ประมาณ)SharpeSortino
Sharpe = (ผลตอบแทนต่อปี − risk-free rate) ÷ ความผันผวนต่อปี — วัดผลตอบแทนส่วนเกินต่อหน่วยความเสี่ยงทั้งหมด (ขึ้นและลง) ยิ่งสูงยิ่งดี · Sortino ใช้เฉพาะ "downside deviation" (ความผันผวนขาลงเท่านั้น) แทน จึงไม่ลงโทษความผันผวนขาขึ้น เหมาะกับการเปรียบเทียบกองทุนที่มีลักษณะ return แบบเบ้ (skewed) · ผลตอบแทนต่อปีที่ใช้คำนวณเป็นค่าประมาณจาก NAV รายวัน (ไม่ใช่ XIRR ที่รวมจังหวะเงินเข้า-ออก) · risk-free rate เป็นค่าที่คุณตั้งเอง ปรับได้ตามอัตราดอกเบี้ยพันธบัตร/เงินฝากระยะสั้นที่ใช้อ้างอิง
Correlation Matrix (ผลตอบแทนรายวัน)

กองทุนสัดส่วนปัจจุบันเป้าหมาย % (แก้ไขได้)คำแนะนำ

 อัปเดต NAV อัตโนมัติจาก SEC Open API

        

          ดึง NAV รายวันของกองทุนทั้ง 18 กองทุนอัตโนมัติจาก SEC Open API (proj_id ของทุกกองจับคู่และยืนยันไว้ในโค้ดแล้ว ไม่ต้องค้นหาเอง):

          1. คัดลอกโค้ด Apps Script ด้านบน (มีฟังก์ชัน SEC API รวมอยู่แล้ว) วางทับของเดิมทั้งหมดใน Apps Script Editor → บันทึก

          2. เลือกฟังก์ชัน updateNAVFromSEC จาก dropdown แล้วกด Run ครั้งแรก (ระบบจะขอ authorize ให้กด Allow) เปิด View → Logs เพื่อเช็คว่าดึงครบ 18 กอง

          3. ถ้าตัวเลขถูกต้องครบ เลือกฟังก์ชัน installDailyNAVTrigger แล้วกด Run (ตั้งเวลาดึงอัตโนมัติทุกวันประมาณ 8:00 น.)

          4. กดปุ่มด้านล่างเพื่อทดสอบดึงจากในแอปได้เลย

        

        
        

      


      

        
 ราคาทองคำ (GOLD-HSH) — กรอกเอง

        

          dailyAutoUpdate ที่รันอัตโนมัติทุกวัน 8:00 น. ตอนนี้จะอัพเดตเฉพาะ NAV กองทุนจาก SEC API เท่านั้น — ราคาทองไม่ถูกดึงอัตโนมัติอีกต่อไป (API ราคาทองภายนอกอ่านค่าไม่ได้บ่อยครั้ง)

          วิธีอัพเดตราคาทอง: กรอกราคาทองคำแท่งของวันนี้ (บาท/กรัม) เองทุกวันผ่านแท็บ "บันทึก NAV"

          ปุ่มด้านล่างยังใช้ทดสอบดึงราคาจาก API ได้เผื่ออยากเช็คราคาไว้อ้างอิงตอนกรอกมือ แต่จะไม่รันอัตโนมัติแล้ว
